# Blackout Map – Power Outage Reporting System

A web application built with Python and Flask to report 
and track real-time power outages with map-based visualization.

## Features
- Report power outages by location
- View and track outage history
- Simple and user-friendly interface

## Tech Stack
- Python
- Flask
- HTML/CSS

## How to Run
1. Install dependencies: pip install flask
2. Run the app: python app.py
3. Open browser: http://localhost:5000
